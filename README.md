# SWYNEX Task 2: Exploratory Data Analysis

## Dataset
Cleaned Titanic passenger dataset from Task 1 (784 rows after removing duplicates and handling missing values).

## Tools Used
Python, Pandas, Seaborn, Matplotlib, Google Colab

## Statistics Calculated
- Average age: 29.6 years (oldest passenger: 80)
- Average fare: 34.7 (median fare: 15.9, highest fare: 512.33)
- Overall survival rate: about 41%
- Survival rate by sex, passenger class and age group

## Key Insights
1. Women survived far more than men: about 74% of women survived compared with about 22% of men.
2. Passenger class mattered a lot: first class survival was about 63%, second class about 51% and third class only about 26%.
3. Children had the best survival chance (about 57%), while seniors had the lowest (about 23%).
4. Most passengers were young adults, with the age distribution peaking around 28 to 30 years.
5. A few very expensive tickets skew the fares: the average fare (34.7) is much higher than the median fare (15.9). Some passengers also have a fare of 0, which is an anomaly.
